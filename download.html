Installation

Install Uppidi Fleet

Choose your installation method. Paseo 0.9+ required.

From npm (Recommended)

paseo plugin add npm:@xpufx/paseo-uppidi-fleet

The npm package is @xpufx/paseo-uppidi-fleet; the plugin installs and displays as uppidi-fleet (the id in paseo-plugin.json).

View on npm →

From Git Repository

paseo plugin add xpufx/paseo --path plugins/uppidi-fleet

Installs directly from the paseo monorepo. Useful for testing unreleased changes or forks.

After Installation

  1. The plugin appears as a sidebar item and a workspace panel named Uppidi Fleet.
  2. Open Settings in the panel to configure the hook service (listen host/port).
  3. Register your Forgejo/Gitea host, repo, and PAT via environment variables or config files (see Prerequisites).
  4. Seed board labels using the label-base.yaml template.
  5. Add webhooks on your Forgejo repos pointing to the router (default http://:8099/forgejo).
  6. Adapt the example Skills in examples/skills/ for your environment and load them into your Paseo skills directory.
